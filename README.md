# 🌐 README – `fitconnect-frontend`

# FitConnect – Frontend (React + TypeScript)

Frontend web de FitConnect, consommant l’API GraphQL de la Gateway et les WebSockets du Chat Service.

---

## Stack

- React
- TypeScript
- GraphQL (Apollo Client ou urql)
- WebSocket (pour le chat et les notifications)
- TailwindCSS ou MUI

---

## Fonctionnalités

- Authentification (login / signup)
- Dashboard utilisateur
- Vue communauté (groupes, membres)
- Planning & événements
- Challenges & classements
- Chat en temps réel

---

## Installation

```bash
npm install
npm run dev
